# Data-for-social-good

The MLB Historical Success Analysis program uses historical baseball data to compare the success of different Major League Baseball franchises
Using Java, object-oriented programming, arrays, loops, and conditional statements, the program organizes and analyzes baseball statistics. It identifies the franchise with the most World Series championships
User Story
As a baseball fan, I want to compare the historical performance of MLB franchises using wins, losses, World Series championships, and winning percentages, so that I can understand which teams have been the most successful throughout baseball history.
Dataset: Lahman Baseball Database The Lahman Baseball Database contains historical baseball statistics dating back to 1871. This project uses historical team and franchise information to compare the success of different MLB teams.
Columns Used
name (String): The name of the MLB franchise.
W (int): The total number of wins.
L (int): The total number of losses.
titles (int): The number of World Series championships won by a franchise.
percentage (double): The team’s winning percentage.
Dataset Files
Teams.txt: Contains historical team statistics, including wins and losses.
TeamsFranchises.txt: Contains franchise identification and names.
SeriesPost.txt: Contains postseason series information used to identify championships
